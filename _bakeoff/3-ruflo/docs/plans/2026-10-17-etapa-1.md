# Etapa 1 — Núcleo + Escopo + Cronograma + Governança — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a Etapa 1 do SPEC-FINAL §15: SPA local-first de um projeto com Dexie/Repository, export/import/apagar, exemplos, configuração de módulos, cadastro de pessoas e organizações, Escopo (requisitos, EAP, entregáveis categorizados, mudanças), Cronograma (CPM, marcos, Gantt, Curva S física, caminho crítico), Governança (painel RAG, abertura/encerramento, normas, template, estratégia de aquisições, reuniões, lições) e linha de base versionada.

**Architecture:** Camadas `shared → core → module-logic → project → analytics → commands → platform → module-ui/registers → app` (ARCHITECTURE-FINAL §3). Escrita = comando puro → `Changeset` → transação Dexie única validada por Zod e integridade. Leitura = `useLiveQuery` → `ProjectSnapshot` → `deriveProject()` puro → indicadores. Três registros estáticos tipados por `ModuleId` (`MANIFESTS`, `INDICATORS`, `VIEWS`).

**Tech Stack:** Vite 5, React 18.3, TypeScript 5 (`strict`, `noUncheckedIndexedAccess`), Zod 3, Dexie 4 + `dexie-react-hooks`, React Router 6 (hash router), Recharts 2, lucide-react, `@fontsource/ibm-plex-mono`, Vitest 2 + Testing Library + jsdom + `fake-indexeddb` 6, Playwright 1.4x, ESLint 9 + `eslint-plugin-boundaries`, Prettier 3. **Sem** Zustand, `idb`, react-hook-form, date-fns.

**Spec:** `SPEC-FINAL.md` e `ARCHITECTURE-FINAL.md` (nesta pasta). O executor lê os dois. Refina `plan-etapa1-sp.md`: mesmos cálculos e casos de teste de CPM/progresso, nova persistência (Dexie + Changeset), mudanças movidas para Escopo, entregáveis com categoria/tipo/template, organizações com papéis múltiplos.

Caminhos e comandos são relativos à raiz do app (criada na Task 1).

## Global Constraints

- TypeScript `strict: true`, `noUncheckedIndexedAccess: true`; sem `any` explícito fora de testes e de `project/snapshot.ts#getItems/setItems`.
- UI em pt-BR; datas exibidas `DD/MM/AAAA`; números com vírgula decimal (`0,92`, `45,5%`); dinheiro `R$ 1.234,56`.
- Modelo: datas ISO `YYYY-MM-DD` com aritmética UTC; durações em dias corridos inteiros; término **inclusivo**; dinheiro em centavos inteiros.
- IDs `crypto.randomUUID()`; códigos humanos separados, gerados por `project.counters`, **nunca reutilizados**: `PI-001`, `REQ-001`, `ENT-001`, `MUD-001`, `M-001`, `NRM-001`, `REU-001`, `LIC-001`; EAP `1.2.3`.
- Nada é gravado no IndexedDB antes de "Criar projeto" ou "Importar". Nenhuma requisição de rede.
- Exemplos nunca entram em comandos, snapshot, analytics ou exportação.
- Nenhum módulo grava em outro; linha de base só muda por "Definir linha de base" (v1) ou "Aplicar à linha de base" numa mudança `Aprovada`.
- **Processos não existe** em nenhuma tela, rota, coleção ou enumeração.
- Tokens: `--bg:#f5f7fa`, `--primary:#3f6d8f`, `--ink`, `--ink-soft`, `--red`, `--amber`, `--gold`, `--green`, `--blue`, `--gray` + `-soft`; `.tb-mono` = IBM Plex Mono.
- Padrões: SPI verde ≥ 0,95, amarelo ≥ 0,85; tolerância de marco 5 dias; mudança parada > 15 dias.
- Fases padrão: Conceituação, Análise, Planejamento de Gestão, Planejamento de Engenharia, Execução, Diligenciamento, Testes, Validação, Serviços, Faturamento, Pagamento, Expedição, Garantia.

## Review Focus

1. **Navegador limpo e IndexedDB indisponível** → nenhum banco `pmb` criado até a primeira ação; se o IndexedDB falhar ao abrir, tela "Este navegador não permite salvar dados. Use uma janela normal ou outro navegador." Testes nas Tasks 14 e 16.
2. **Pacote não iniciado cujo início calculado já passou da data de status** → reprojetado para começar na data de status. Teste na Task 6.
3. **Importação não-JSON, de outro app, de versão mais nova ou com vínculo órfão** → recusada com a mensagem específica e nada gravado. Teste na Task 10.
4. **Sem pacotes, sem linha de base, status antes do início** → `null`/"n/a"/estado vazio, nunca `NaN`/`Infinity`. Testes nas Tasks 7, 12 e 19.
5. **Falha no meio de uma rebaseline ou de uma gravação inválida** → nada é gravado (nem a LB nova, nem a mudança `Implementada`). Teste na Task 14.
